# ADHD Flow UI

React + TypeScript + Vite frontend for ADHD Flow.

## Setup

```bash
cd src/ui
npm install
npm run dev
```

The UI provides an interactive interface for running brainstorming sessions, viewing results in multiple formats (markdown, JSON, YAML, Graphviz, HTML), and pushing ideas to GitHub, Linear, Notion, Google Docs, or Slack.

## Development

- `npm run dev` — start dev server with HMR
- `npm run build` — production build
- `npm run lint` — run ESLint
